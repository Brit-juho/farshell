# MCP·스킬·플러그인 관리

도크의 **MCP · 스킬 관리**를 열어 **FarShell 전체**와 **선택한 세션**을 전환합니다.

- **FarShell 전체:** 기본 사용자 설정, 등록된 프로젝트·CLI의 프로젝트 기록, 실행 중인 세션에서 확인한 프로필을 모읍니다. 확인한 프로필 경로는 다음 조회에도 유지됩니다. 홈 전체를 검색하거나 파일을 자동 이동하지 않습니다. 자료가 많으면 설정 위치 32개씩 나누어 순차적으로 불러옵니다.
- **선택한 세션:** 실제 Claude·Codex 프로세스의 설정 경로와 프로젝트를 사용합니다. 확인할 수 없는 프로필을 기본 프로필로 추측하지 않습니다.
- 종류·도구·적용 범위·카테고리·검색으로 목록을 좁힙니다. 항목을 펼치면 원본 위치, 프로필, 범위, 출처와 설명을 확인합니다. 사용자·프로필 설정은 다른 세션에도 영향을 주며 프로젝트 공용 파일은 팀과 공유될 수 있습니다.

## 정리와 프리셋

카테고리는 용도별 분류이고 프리셋은 함께 적용할 켬·끔 구성입니다. 읽기 전용 항목도 선택해 분류할 수 있습니다. 출처는 개인 작성·Git 저장소·마켓플레이스·로컬 설치·미확인으로 구분합니다.

활성화 가능한 MCP·스킬·플러그인을 선택해 함께 켜거나 끕니다. 프리셋 저장은 선택 항목의 현재 켬·끔 상태를 기록합니다. 적용 전에 대상 파일과 프로필을 검토하며, 프리셋에 없는 항목은 유지됩니다. 원본 파일·세션이 바뀌거나 대상이 사라지면 다시 검토해야 합니다. 여러 파일의 변경은 전체 원자적 작업이 아니며 부분 실패를 항목별로 표시합니다.

플러그인 스킬과 MCP는 부모 플러그인 아래 표시됩니다. 설치·업데이트·제거는 해당 CLI의 부모 플러그인 관리 명령을 사용합니다. 직접 설치한 Claude 스킬의 활성화는 CLI에서 관리하며, Codex 스킬은 네이티브 비활성화 설정을 사용합니다. 링크된 스킬도 표시하지만 링크를 따라 편집하지 않습니다.

원본 편집은 직접 설치한 스킬과 지원되는 MCP 정의에 사용합니다. MCP에는 변경할 필드만 JSON으로 입력합니다. 생략한 필드와 기존 비밀값은 보존하며 기존 인자·URL·자격증명 값은 화면에 반환하지 않습니다. Codex는 안전하게 특정할 수 있는 TOML 할당만 수정하고 그 밖의 설정은 보존합니다. 지원하지 않는 형식은 변경하지 않습니다. 기존 보관함·가져오기·배포 기능은 **기존 MCP 보관함·상세 관리**에서 이용합니다.

## 환경변수와 반영

선택한 로컬 세션의 환경변수는 **머신 공통 → 프로필 유저 → 프로젝트 전용** 순으로 덮어씁니다. 이는 FarShell이 재시작하는 CLI의 실행 환경입니다. 기존 셸 파일이나 실행 중인 프로세스를 직접 수정하지 않습니다. 값은 개인 상태 파일에 0600 평문으로 저장하며 변수 이름과 저장 여부만 화면에 표시합니다. 로그인·OAuth 파일은 복제하지 않고 실행 경로·로더·보안 경계 변수는 변경하지 않습니다.

**안전할 때 CLI 재시작**은 기존 실행 인자와 대화 ID를 확인하고, 작업·승인 대기·사람 입력·미전송 문장이 있으면 기다립니다. 정상 종료 뒤 동일 프로필·위치·대화로 이어갑니다. 지원하지 않는 wrapper, 임시 프로필, 알 수 없는 인자·입력 화면에서는 자동 종료하지 않습니다. 대기는 취소할 수 있고 15분 후 만료됩니다. 서버 재시작 후 대기 작업은 자동 복원되지 않습니다.

CLI 재실행 확인은 MCP 연결 성공과 다릅니다. MCP 실제 실행 상태는 미확인으로 남깁니다. FarShell 서버나 터널 자체를 재시작하는 기능은 아닙니다. 같은 터미널에 직접 연결된 외부 프로그램의 동시 입력까지 원자적으로 통제하지는 못합니다.

## 업데이트·동기화·원격 승인

업데이트는 출처를 입증할 수 있는 자료만 판정합니다. 전용 GitHub 스킬 저장소는 공개 원격 커밋을 조회하고 로컬 수정은 별도 표시합니다. Claude 플러그인은 로컬 마켓플레이스 버전과 대조하므로 원격 최신 여부를 보장하지 않습니다. 확인할 수 없는 자료는 최신으로 표시하지 않으며 자동 다운로드·덮어쓰기는 하지 않습니다.

동기화 화면은 기존 peer-sync의 설치·활성 스케줄러·잠금 기록·MCP 충돌 기록 수·최근 로그 시각을 표시합니다. 로그 내용과 비밀값은 반환하지 않습니다. 기존 실행 주체의 활성 스케줄러만 실행할 수 있고 새 동기화 엔진은 만들지 않습니다. 카테고리·프리셋·환경변수·재시작 기록은 해당 호스트에 저장되며 기존 peer-sync 범위를 자동 확장하지 않습니다.

원격 쓰기는 대상 호스트의 승인 요청이 됩니다. **대상 호스트에 직접 로그인한 사람이 원격 승인에서 검토하고 승인해야** 적용됩니다. 호스트 권한이 회수되거나 계획이 만료되면 중단합니다. 환경변수·분류 등 직접 원격 지원하지 않는 작업은 해당 호스트에서 관리합니다. 양쪽 FarShell에 이 기능이 필요합니다.
