# 사용량 표시 (clauth 연동)

FarShell은 웹/모바일 UI에 **사용량 게이지**를 띄울 수 있다(데스크톱은 활동 막대 「사용량」, 상태 막대 사용량 칩). 데이터는
[clauth](https://github.com/uwuclxdy/clauth)가 쓰는 상태 피드에서 읽는다.

**clauth를 쓰지 않으면 이 기능은 조용히 사라진다** — 설정할 것도, 에러도 없다.

## 확인

```bash
fsh clauth status     # 프로필별 사용량 (읽기 전용)
fsh clauth which      # 지금 활성 프로필 이름만
fsh doctor            # 피드 신선도까지 함께 진단
```

웹에서는 활동 막대의 「사용량」(게이지 아이콘)이 사이드바에 연다. 소스가 없으면 그 활동 자체가 안 보인다.

## 어떻게 읽나

`~/.clauth/status.json` **하나만** 읽는다. FarShell은 이 파일이 기본 90초 주기로
갱신된다고 보고(`server/usage/clauth.py`) mtime이 바뀌었을 때만 다시 파싱한다.

`clauth status --json`을 실행하지 않는 이유: 폴링마다 프로세스를 띄우게 되고,
`pending_switch` 같은 값은 단발 실행에서 관측되지 않는다(데몬만 안다).

**토큰·credential은 응답에 싣지 않는다.** 서버가 필드 화이트리스트로 걸러서
내보내므로, clauth가 나중에 민감한 필드를 추가해도 웹으로 새지 않는다.
이 레거시 피드 경로는 `token_ledger.json`·`profiles/`·`session_profiles.json`을 읽지 않는다. 별도의 [실행 프로필 관리](profiles.md)는 명시적 검토 과정에서 선택한 이전 원본을 읽는다.

## 끄기 / 강제하기

`~/.vt.env`의 `VT_USAGE_PROVIDER`:

| 값 | 동작 |
|---|---|
| `auto` (기본) | 피드가 있으면 표시, 없으면 숨김 |
| `clauth` | 강제. 피드가 없으면 **이유를 표시**한다(왜 안 뜨는지 알고 싶을 때) |
| `native` | clauth 피드와 기본 Codex 자격증명 대신 관리 프로필의 네이티브 사용량만 읽음 |
| `none` | 기능 자체를 끈다. 공개 터널로 사용량을 내보내기 싫을 때 |

```bash
source lib/vt_env.sh                 # 저장소 루트에서 실행
vt_env_set VT_USAGE_PROVIDER none
```

## 표시 규칙

- 바 색: 80% 초과 앰버, 95% 초과 빨강
- 피드가 갱신 주기의 2배를 넘겨 멈추면 **"갱신 멈춤"** + 흐리게
- `auth_status`가 정상이 아니면 **게이지보다 위에** "재인증 필요"
- 창(`5h`/`7d`) 정보가 없는 프로필은 빈 바 대신 **"사용량 정보 없음"** —
  0%로 그리면 "안 쓰고 있다"는 거짓 정보가 된다

## 프로필 전환과 세션 표시의 범위

**프로필 전환(`clauth <profile>`)은 웹에서 제공하지 않는다.** FarShell은 tmux
세션을 여러 개 띄우는 도구라, 세션 5개를 돌려놓고 전역 프로필을 바꾸면 기존
세션은 그대로고 새 세션만 바뀐다 — 어느 세션이 어느 계정인지 알 수 없게 되고,
폰으로 원격에서 볼 때 특히 위험하다. 전환은 터미널에서 clauth 자체 명령으로.

같은 이유로 **탭·pane마다 프로필 배지를 달지 않는다.** 피드는 "이 프로필로 도는
세션이 있다"까지만 알려주고 어느 tmux 세션인지는 알려주지 않는다. 매핑 없이
배지를 붙이면 틀린 계정을 확신 있게 표시하게 된다. 「사용량」 화면 안에 활성 프로필과
실행 여부만 전역 지표로 표시한다.
