# 웹 UI 사용 설명서

브라우저에서 FarShell을 쓰는 방법 전체. (CLI는 `fsh help concepts`, 음성은 `fsh help voice` 참고)

---

## 1. 접속

| 환경 | 방법 |
|------|------|
| 데스크톱 | `http://localhost:7777` |
| 같은 와이파이 모바일 | `fsh start --network lan` 후 서버의 LAN IP와 포트로 접속 |
| 어디서든(원격) | `fsh start` 후 `fsh mobile` → 설정한 터널의 HTTPS URL / QR |
| 회사망 등 | `fsh start --network tailscale` (tailnet 제한) |

> 인증이 설정되어 있으면 `fsh mobile` URL에는 5분 유효한 1회용 기기 등록 티켓이
> 붙습니다. 이 링크를 공개하지 마세요. 일반 접속은 비밀번호로 로그인합니다.

---

## 2. 세션과 뷰

- **세션**: tmux 세션 하나. 종료하기 전까지 계속 돌아갑니다(claude 등 안의 작업도 그대로).
- **뷰**: 칸(pane) 배치 하나. 칸이 하나면 단일 뷰, 둘 이상이면 묶음 뷰입니다. 데스크톱에는 뷰 탭 줄이 없고, 사이드바 「세션」에서 세션이나 묶음을 눌러 그 뷰로 갑니다.
- **열림**: 세션이 이 브라우저 탭의 칸에 놓여 있는 것. 상태가 아니라 배치입니다.
- 브라우저 탭마다 뷰 배치가 따로 저장됩니다. 새로고침해도 **닫은 세션은 다시 열리지 않습니다.**

### 제목 막대 · 상태 막대 (데스크톱, 폭 720px 이상)

- **제목 막대**(맨 위): 왼쪽부터 **FarShell 메뉴**(새 세션 · 빠른 열기 · 집중 모드 · 접속 주소 복사 · 설정 · 상태 막대 설정 · 캐시 지우기 · 로그아웃,
  승인 대기 수가 배지로 붙습니다. 「캐시 지우기」는 저장된 앱 파일만 지우고 새로고침하며 설정·로그인은 그대로입니다(제목 막대가 없는 폰에서는 설정 › 정보 및 진단 › 앱 파일의 「캐시 지우기」 단추로 같은 일을 합니다). 「로그아웃」은 이 브라우저의 로그인만 끝내고 기기 등록은 남깁니다), 이 화면이 보고 있는 **맥**(다른 맥과 페어링돼 있으면 눌러서 화면 전체를 그 맥으로
  바꿉니다), 지금 칸의 **저장소 › 브랜치 › 세션**(폭 1280px 미만에서는 숨김). 가운데 **검색하거나 명령 실행** 칸을
  누르거나 `Cmd+K`를 누르면 팔레트가 열립니다. 오른쪽에는 집중 모드 버튼(네 모서리 아이콘), 키바 버튼(터치 기기)과 창 버튼이 있습니다.
- **상태 막대**(맨 아래): 맨 왼쪽은 **에이전트 칩**(`개입 N · 작업 N · 완료 N`, 개입이 있으면 눌러서 가장 오래 기다린
  세션으로 갑니다)으로 고정이고, 짧은 알림(복사했습니다 등)은 그 바로 오른쪽에 잠깐 뜹니다. 이어서 E2E · 세이프모드 ·
  연결된 화면, 오른쪽에 CPU · GPU · RAM · 네트워크 · 사용량 · 알림 · 버전 · 시계가 나옵니다. 값이 없는 칩은 안 보이고,
  폭이 모자라면 덜 중요한 칩부터 숨습니다. 무엇을 어디에 둘지는 설정 → **상태 막대**에서 바꿉니다(이 기기에만 저장,
  에이전트 칩은 옮기거나 끌 수 없습니다).
- 폰(720px 미만)에는 두 막대가 없고 상단바와 하단 탭이 그 역할을 합니다.
- **집중 모드**(넓은 화면): `Cmd+.`(맥 밖에서는 `Alt+Shift+.`), 제목 막대 오른쪽 버튼, FarShell 메뉴, 팔레트(「집중 모드」)로
  켜고 끕니다. 활동 막대 · 사이드바 · 제목 막대 · 상태 막대를 숨기고 칸을 창 끝까지 넓힙니다(터미널 크기는 들어갈 때 · 나올 때
  한 번씩만 바뀝니다). 화면 왼쪽 · 위 · 아래 가장자리에 마우스를 잠깐 대면 그쪽 막대가 칸 위에 떠오르고(칸 크기는 그대로),
  벗어나면 다시 숨습니다 — 왼쪽은 세션을 고르거나 `Esc`면 바로 닫힙니다. 승인을 기다리는 세션이 있으면 오른쪽 위 알약에
  「개입 N · 이름 · 종류」가 보이고 누르면 그 세션으로 갑니다. 알약 오른쪽 「끝내기」로도 나옵니다. 토스트 · 승인 창 · 팔레트는
  그대로 뜹니다. 설정 → 모양 「집중 모드」에서 가장자리 띄우기 · 개입 표시 · 가장자리 반응 시간(바로 / 250ms / 500ms)을 바꿉니다.
  마우스가 없는 태블릿은 가장자리 대신 왼쪽 아래 끝내기 버튼을 씁니다. 새로고침하거나 창 폭이 720px을 넘나들면 꺼집니다.
- **폰 마이크**: 터미널 탭 오른쪽 아래에 떠 있는 둥근 마이크(아래 탭 위, 키바를 열면 키바 위)를 누르면 녹음, 다시 누르면 끝납니다.
  점이 붙어 있으면 음성 준비가 필요하다는 뜻입니다(길게 누르면 음성 패널).
- **폰 집중 모드**: 터미널 탭 상단바의 첫 버튼(네 모서리 아이콘)을 누르면 상단바와 하단 탭을 숨기고 터미널과 키바만 남깁니다.
  마이크는 키바 첫 키로 옮겨 갑니다. 오른쪽 위 작은 알약에 승인을 기다리는 세션이 「개입 N 이름」으로 보이고 누르면 그 세션으로 갑니다.
  나가려면 알약의 나가기 버튼을 누르거나, 화면 맨 위 가장자리에서 아래로 끌어내렸다 놓습니다(조금만 끌면 그대로).

### 작업대 — 활동 막대 · 사이드바 (데스크톱, 폭 720px 이상)

- **활동 막대**(맨 왼쪽 48px 세로 막대): 위 무리는 사이드바에 띄울 것 — 세션 · 변경 · 파일 · 큐 · 첨부 · 스니펫 · 포트 · 사용량 ·
  시스템(포트 · 사용량은 쓸 수 있을 때만). 아래 무리는 MCP · 스킬 관리 · 마이크 · 설정(승인 대기 수가 배지로 붙습니다).
  지금 활동은 왼쪽 2px 파란 선으로 표시됩니다. 아이콘에 마우스를 올리면 이름이 뜹니다.
- **사이드바**: 활동 막대 오른쪽 칸 하나. 폭은 모든 활동이 함께 씁니다(기본 360, 오른쪽 끝을 끌어 240–480) — 활동을 바꿔도
  터미널 크기가 변하지 않습니다. 지금 활동을 다시 누르거나 `Cmd+B`(맥 밖에서는 `Alt+Shift+B`)로 접고 폅니다. 「세션」은 48px 띠로,
  도구는 0으로 접힙니다. 도구 아이콘을 칸으로 끌어 놓으면 그 도구가 칸에 열립니다.
- **오른쪽에 고정**: 도구 패널 머리의 「오른쪽에 고정(나란히 보기)」 버튼을 누르면 그 도구가 화면 오른쪽 300px에 고정되고 왼쪽
  사이드바는 「세션」으로 돌아갑니다 — 세션 목록과 변경 · 큐 같은 도구를 나란히 봅니다. 고정한 도구의 활동 아이콘에는 오른쪽 위에
  작은 파란 점이 붙습니다. 같은 버튼(「오른쪽 고정 해제」)이나 패널을 닫으면 고정이 풀립니다. 폭 1280px 이상에서는 칸 옆에
  자리를 차지하고, 그보다 좁으면 칸 위에 떠 있는 서랍이 됩니다(칸 크기는 그대로). 집중 모드에서는 숨습니다. 이 기기에만 저장됩니다.

### 사이드바 「세션」 (세션 목록)

세션은 저장소별로 묶여 나옵니다. 저장소 머리에는 이름과 메인 브랜치가 있고, 세션은 처음 시작한 저장소에 남습니다(cd로 옮겨도 그대로).
같은 저장소의 다른 워크트리에서 작업 중인 세션은 「워크트리 <브랜치>」 가지 아래에, 저장소가 아닌 곳의 세션은 맨 아래 「저장소 밖」에 나옵니다.
입력을 기다리는 세션은 위의 「개입 필요」 구역으로 올라갑니다. 저장소 순서는 입력 대기가 있는 저장소 → 최근 활동순입니다.
칸 하나는 두 줄입니다: 상태 링과 에이전트 · 이름 · 경과 · ⋯ / (할 말이 있을 때만) 입력 대기 유형 · 작업 중인 도구 · 「끝남 · 확인 안 함」 · 마지막 지시와 변경량.
저장소 맨 아래 「종료 N」을 펴면 그 저장소에서 끝난 세션이 나오고, 「이어서」 버튼은 늘 보입니다. 칸을 누르면 연결된 대화와, 이어서 시작하면 어느 폴더에서 어떤 이름으로 열리는지가 나옵니다.

| 동작 | 결과 |
|------|------|
| 행 클릭 (안 열린 세션) | 새 뷰로 엽니다. 닫았던 묶음 뷰의 일원이면 묶음 전체를 다시 엽니다 |
| 행 클릭 (이미 열린 세션) | 그 뷰로 가서 그 칸에 포커스 |
| 행 ⋯ / 우클릭 / 롱프레스 (메뉴) | 메뉴 맨 위 한 줄에 상태 · (입력 대기면) 유형 · 웹 외 N · 만든 곳 · 브랜치가 요약돼 나옵니다(터치에는 호버 툴팁이 없어서). 눌러도 아무 일도 없는 안내 줄입니다 |
| 행을 칸 가장자리로 드래그 | 그 방향으로 분할 — 세션을 묶는 방법(터치 기기는 아래 메뉴 항목도 가능) |
| 행 메뉴 「오른쪽에 나란히 열기」「아래에 열기」 | 폭 720px 이상의 터치 기기(태블릿)에서만 나옵니다. 활성 칸을 그 방향으로 나누고 그 세션을 놓습니다(다른 뷰에 있던 세션은 옮겨 오고, 비게 된 뷰는 닫힙니다). 720px 미만 폰에는 없습니다 |
| 칸 `×` | 세션이 사이드바에서 「안 열림」이 됩니다(tmux는 그대로). 칸은 빈 칸으로 남습니다 |
| 묶음 머리의 닫기 | 묶음 뷰만 닫습니다. 구성을 기억해 두었다가 사이드바에서 다시 엽니다 |
| 행의 `⋯` 또는 우클릭 | 열기/닫기 · 이름 변경 · 맥에서 열기 · 연결된 화면 · 에이전트 공유 항목(아래) · **종료** |

- **종료**는 tmux 세션과 그 안의 claude/셸까지 되돌릴 수 없이 끝냅니다. 항상 확인창이 뜨고,
  작업 중이거나 입력 대기 중이면 그 사실을 경고합니다. 다른 브라우저 탭에서 열려 있던 칸은 빈 칸이 됩니다.
- **모바일 세션 관리**: 상단 세션 이름을 누르면 하단 「세션」 탭과 터미널을 오갑니다. 세션 목록의 행 메뉴에서 열기·닫기·이름 변경·종료를 실행합니다.
- **모바일 이동 순서**: 좌우 스와이프, 상단 `n/m`, 팔레트가 같은 순서를 씁니다.
  뷰 순서 → 뷰 안 칸 순서(왼쪽 위부터)이고, 빈 칸은 건너뛰며 끝에서 처음으로 이어집니다. 이동은 세션을 옮기지 않고
  그 세션의 뷰·칸으로 갈 뿐입니다. 순서를 바꾸려면 모바일 「세션」 탭의 「뷰 편집」을 켜고
  뷰 단위로 위·아래 버튼을 누르세요. 묶음 뷰는 함께 움직입니다.
  편집 중에는 뷰마다 「닫기」 버튼도 있습니다(세션은 살아 있고, 묶음 뷰는 구성이 기억되며, 마지막 뷰를 닫으면
  시작 화면이 뜹니다). 뷰별 칸 수(빈 칸·파일·패널 포함)도 여기서 봅니다. 폰에서 「세션」 탭을 열 때 비어 있는 단독 뷰(「빈 화면」)는 자동으로 정리됩니다.
- **에이전트와 세션 공유**: 에이전트(Claude Code 등)가 FarShell MCP 도구로 **당신이 공유한 세션만** 읽고 입력할 수 있게 합니다.
  에이전트는 세션을 만들 수도 닫을 수도 없습니다.
  - **공유하기**: 행 메뉴 「공유 및 권한…」 → 「공유 및 권한 · 세션 이름」 창에서 닉네임(영문·숫자·`_`·`-` 1~32자)과 모드(읽기 전용 / 읽기·쓰기)를 정하고 「공유」를 누릅니다.
    공유된 행에는 눈(읽기 전용) 또는 펜(읽기·쓰기) 아이콘과 닉네임이 보이고, 메뉴 맨 위 요약줄에도 나옵니다.
    바꾸려면 같은 창에서 닉네임이나 모드를 고치고 「저장」, 끝내려면 「공유 해제」(그 세션의 모든 권한과 대기 중인 요청이 즉시 사라집니다).
  - **승인하기**: 에이전트가 공유 세션을 처음 쓰면 화면에 「에이전트 접근 요청」 창이 뜹니다. 읽기와 쓰기는 따로 묻고,
    쓰기 요청에는 「읽기만 허용」도 있습니다. 기본 선택은 「거부」이고 창이 뜬 직후 잠깐은 눌려도 반응하지 않습니다
    (치던 키가 승인되지 않도록). 한 번 허용하면 그 에이전트가 `/new`·`/clear`를 해도 계속 쓸 수 있습니다.
    「나중에」(Esc)는 거부가 아니라 보류입니다 — 설정 > 권한 > 「승인 대기」에서 다시 엽니다(설정 버튼의 숫자 배지가 대기 건수입니다).
  - **회수하기**: 행 메뉴 「공유 및 권한…」의 「이 세션에 허용된 권한」에서 권한마다 「입력만 회수」(읽기는 남김) 또는 「회수」를 누릅니다.
    전체 권한은 설정 > 권한 > 「허용된 권한」에서 거를 수 있고, 최근 접근은 「감사 기록」에서 봅니다
    (입력한 글·화면·메시지 내용은 기록하지 않고 길이와 해시 앞 8자리만 남습니다). 회수 뒤 에이전트의 다음 호출은 다시 승인 대기가 됩니다.
  - **한계**: 공유하면 에이전트는 그 세션의 **화면에 보이는 모든 것**을 읽습니다 — 비밀번호·토큰이 보이면 공유하지 마세요.
    읽기·쓰기는 에이전트가 그 터미널에서 명령을 실행할 수 있다는 뜻입니다. 화면 속 글은 그 프로그램이 찍은 것이라
    믿을 수 있는 정도가 그 프로그램만큼이고(프롬프트 주입 가능), 공유는 활성 칸 하나에만 적용됩니다.
    이 승인 장치는 속은 에이전트나 실수로 보낸 호출을 막기 위한 것입니다. 같은 사용자 권한으로 실행되며 파일을
    자유롭게 읽을 수 있는 악의적 프로세스는 `~/.vt.env`의 세션 서명키를 읽어 사람 세션 쿠키를 위조하고 승인을
    통과할 수 있습니다(실제 확인됨). 완전히 신뢰하지 않는 에이전트는 샌드박스나 별도 사용자 계정으로 실행해
    `~/.vt.env`를 읽지 못하게 하세요.
    파일 권한 0600만으로는 같은 사용자 권한의 프로세스를 서로 격리할 수 없습니다. 공유 모드를 읽기로 낮췄다가
    다시 읽기·쓰기로 올리면 이전의 쓰기 승인이 재승인 없이 살아납니다. 영구히 막으려면 쓰기 권한을 철회하거나 공유를 해제하세요.
    다른 맥을 보는 화면에서는 이 기능이 없고, 이름이 한글인 세션은 공유할 수 없습니다(이름을 영문으로 바꾸세요).
    `?token=` 링크로 접속한 화면에서는 승인·공유가 안 됩니다(비밀번호 로그인 필요).
- 사이드바 「세션」 머리의 조절 아이콘 = **세션 목록 설정**: 「개입 필요」 구역 표시, 만든 곳별(다른 맥·외부) 표시, 저장소 표시.

## 3. 새 세션 시작 위치

새로 만드는 세션(일반 셸 / 새 tmux)은 기본으로 **홈 디렉토리(`~`)** 에서 시작합니다.
다른 폴더에서 시작하려면 `~/.vt.env`에:

```bash
VT_START_DIR=~/projects
```

> 이미 존재하는 tmux 세션을 attach하는 건 그 세션 원래 위치를 유지합니다. 이 설정은
> **새로 만드는** 세션에만 적용됩니다.

## 4. 복사 · 붙여넣기 · 이미지

| 하고 싶은 것 | 방법 |
|--------------|------|
| **복사** | 텍스트 드래그 선택 → 자동 복사 ("복사됨" 표시) |
| 복사 (단축키) | 선택 후 `Cmd+C` (mac) / `Ctrl+Shift+C` (Linux/Win) |
| 복사 (우클릭) | 선택이 있는 상태에서 우클릭 |
| **붙여넣기** | `Cmd+V` / `Ctrl+V`, 또는 우클릭(선택 없을 때), 모바일은 롱프레스 |
| **이미지 붙여넣기** | 스크린샷 등 복사 후 `Cmd+V` → 자동 업로드 → **파일 경로가 터미널에 삽입됨** |

### ⚠️ 드래그 복사가 안 될 때 — tmux 마우스 모드

tmux는 기본으로 마우스 모드(`set -g mouse on`)라, **그냥 드래그하면 tmux가 마우스를
가로챕니다.** 그래서 브라우저 텍스트 선택(→ 자동 복사)이 되려면:

- **`Shift`(또는 mac에서 `Option`) 누른 채 드래그**하세요. → 선택되고 자동 복사됨.
- 우클릭 붙여넣기 / 이미지 붙여넣기는 마우스 모드와 무관하게 바로 됩니다.

Shift 없이 그냥 드래그로 복사하고 싶으면 `~/.config/vt/tmux.local.conf`에
`set -g mouse off`를 적고 `fsh tmux reload` 하면 됩니다. 단, tmux 스크롤휠·pane 클릭이 사라지고 iTerm 세션에도
같이 적용됩니다.

### 이미지 워크플로 (Claude Code)

이미지를 붙여넣으면 서버 `~/.vt/files/`에 저장되고 그 경로가 터미널에 입력됩니다.
그 경로를 그대로 claude에 넘기면 됩니다. (📎 파일 업로드 버튼으로도 동일하게 가능)

> 터미널은 텍스트(바이트)만 받는 PTY라 이미지 자체를 "붙여넣어" 화면에 띄울 수는 없습니다.
> 대신 업로드 후 경로를 넘기는 방식입니다.

## 5. 그 밖의 기능

| 기능 | 방법 |
|------|------|
| **검색** | `Cmd+F` / `Ctrl+Shift+F` → 스크롤백 검색, `Alt+Shift+F` → 터미널 안 검색 (▲▼로 이동). 예전 `Cmd+Shift+F`는 이제 파일 내용 검색입니다(직접 바꿔 둔 키는 그대로) |
| **파일 내용 검색** | 팔레트(`Cmd+K`)에 `?`와 찾을 글자(`? groupByZone`) — 결과가 파일별로 묶이고 일치한 곳이 강조됩니다. ↑↓ 이동, Enter는 그 줄로 열기, `Cmd+Enter` 새 칸, `⌥Enter` 사이드바로 옮기기. 옵션: `⌥C` 대소문자, `⌥W` 단어 단위, `⌥R` 정규식(기본은 글자 그대로), 포함·제외 glob(`src/**, *.ts` / `**/*.test.*`). 찾는 범위는 지금 세션의 저장소입니다. `Cmd+Shift+F`(맥) / `Ctrl+Shift+G`는 사이드바 「파일 › 내용 검색」을 열고, 거기서는 트리의 지금 폴더 아래를 찾습니다. `.gitignore`에 든 파일, `.env`·키 파일 같은 비밀 파일, 2 MB 넘는 파일과 바이너리는 찾지 않습니다. 10초·결과 500줄에서 멈추고 그때까지 찾은 것을 보여 줍니다. 다른 맥으로 전환해 있으면 그 맥의 파일을 찾습니다 |
| **파일 업로드** | `⋯ → 파일 업로드` → `~/.vt/files/`에 저장 |
| **Grid 뷰** | 상단 격자 아이콘 → 모든 tmux 세션 라이브 프리뷰 (변화 시에만 push) |
| **테마** | 설정(`Cmd+,`) → 모양 → 스킨 전환 (기억됨) |
| **맥에서도 열기** | `⋯` 토글 ON → 새 세션 생성 시 iTerm 창도 자동 오픈 (macOS) |
| **핸드오프** | `fsh handoff mobile` (폰으로) / `desktop` (맥으로) |
| **파일 트리** | 사이드바 「파일」 활동. 보이는 행만 그려서 큰 폴더도 바로 열리고, 1000개씩 「더 불러오기」로 이어 봅니다. 키보드: ↑↓ 이동, ←→ 접기·펼치기, Enter 열기, ⌥Enter 터미널에 경로 삽입, ⇧F10 행 메뉴, 글자 입력으로 이름 찾기, `/` 이름 필터(`rail`, `*.tsx`). 오른쪽 클릭 메뉴: 열기 · 경로 삽입 · 경로 복사 · 다운로드 · 공유 링크 · 새로고침. 디스크에서 바뀐 파일은 파란 점, 그 위 폴더는 빈 원으로 표시되고 파일을 열면 사라집니다. 행 높이는 설정 → 모양 → 「파일 트리 촘촘하게」(28px → 22px) |
| **미리보기** | 마크다운은 렌더된 모습으로 열리고 위 띠의 「렌더 \| 원문」으로 바꿉니다(원문 HTML은 글자로 보이고, 외부 이미지는 막힙니다). CSV·TSV는 표(1MB까지), SVG는 그림으로만(안의 스크립트는 실행되지 않음), 동영상(mp4·webm)·소리(mp3·m4a·wav)는 브라우저 재생기로 봅니다. PDF는 미리 보지 않고 다운로드만 됩니다 |
| **다운로드** | 트리 행 메뉴, 뷰어 머리줄(폰 포함), 페인 뷰어, 바이너리·PDF 화면에서 실제 파일을 받습니다. 보고 있던 판과 디스크가 다르면 받지 않고 알립니다. 크기 상한은 `VT_MAX_UPLOAD_MB`. 이 컴퓨터의 파일만 됩니다 — 원격 호스트를 보는 중이면 단추가 흐리고 이유가 붙습니다 |
| **편집 · 저장** | 뷰어 위 띠의 「편집」을 누르면 그 자리에서 고칩니다(자동 저장 없음). ⌘S / Ctrl+S 또는 「저장」으로 저장하고, 처음 저장할 때 **웹 로그인 비밀번호**를 한 번 묻습니다(이 기기에서 15분 유지). 2 MB 이하 · 파일 전체를 받은 텍스트 · 인코딩을 확신하고 줄 끝이 한 가지인 파일만 됩니다(아니면 「편집」이 흐리고 이유가 붙습니다). 저장 전에 다른 곳에서 파일이 바뀌면 덮어쓰지 않고 충돌 배너가 뜹니다 — 「비교」 · 「다시 불러오기」 · 「내 것으로 덮어쓰기」. 편집 중에는 줄 번호 옆에 바뀐 줄이 표시됩니다(추가 = 초록 막대, 수정 = 파란 점선 막대, 삭제 = 빨간 쐐기, 불러온 판이나 마지막 저장 기준). 고친 채 뷰어를 닫거나(× · Esc · 폰 뒤로가기) 다른 파일을 열거나 그 칸을 닫으면 「저장 / 버리기 / 취소」를 묻습니다(Esc와 기본 초점은 「취소」, 「저장」은 저장이 성공해야 닫힘). 뷰어를 다른 표면으로 옮길 때는 묻지 않고 고친 내용을 보관했다가 이어 엽니다. 폰에서는 편집 띠가 위에 붙어 있어 키보드가 올라와도 「저장」이 보입니다 |
| **새 파일 · 새 폴더 · 이름 바꾸기 · 삭제** | 트리 행 메뉴(「이 폴더에 새 파일…」 · 폴더 행의 「이 폴더에 새 폴더…」 · 「이름 바꾸기…」 · 「휴지통으로 이동…」)와 뷰어 위 띠. 같은 이름이 있으면 만들거나 바꾸지 않습니다(덮어쓰지 않음). 삭제는 **OS 휴지통으로 옮기기**뿐이라 되돌릴 수 있습니다(macOS는 Finder 「되돌리기」, Linux는 데스크톱 휴지통). 휴지통을 쓸 수 없는 곳이면 지우지 않고 알립니다. 폴더는 안의 내용과 함께 휴지통으로 옮깁니다. 심링크, 열람 · 쓰기 루트 폴더 자체, 폴더를 자기 안으로 옮기기는 거부합니다. 쓰기는 이 컴퓨터의 파일에서만, 쓰기 경계(`VT_WRITE_ROOTS`, 기본은 열람 경계) 안에서만 되고, `.github` · `.vscode` 같은 실행 설정 폴더는 쓰지 않습니다 |
| **폰 「파일」 탭** | 아래 탭 넷째 칸. 파일 트리가 기본이고, 맨 위 「파일 \| 첨부」로 첨부 화면을 오갑니다(마지막에 본 쪽을 기억). 올리는 중 배지는 이 탭에 붙습니다. 행을 길게 누르면 행 메뉴가 아래 시트로 열립니다 |
| **가로 폰 + 소프트 키보드** | (자동 집중) 키보드로 보이는 높이가 300px 미만이 되면 탭 바·칸 헤더·작업대를 숨기고 터미널이 남은 높이를 다 씁니다. 키보드를 내리면 원래 화면으로 돌아옵니다. (세로 폰에서는 키보드가 떠 있는 동안 하단 내비가 숨는데, 의도된 동작입니다) |

|------|-------------|

## 대화 재개 시 권한 설정

「이어서 시작」과 대화 보관함의 「이어가기」는 마지막으로 기록된 권한 설정도 복원합니다.

세션 목록 맨 아래 「보관함」을 누르면 보관한 세션을 이름·대화·브랜치·마지막 지시·폴더로 검색하고, 저장소 칩으로 그 저장소(루트 폴더)의 세션만 볼 수 있습니다.
「+ 새 세션」은 저장소를 먼저 고르는 메뉴이고, 오른쪽 회색 글자가 열릴 세션 이름입니다. 저장소 머리의 「+」는 그 저장소에서 바로 새 세션을 엽니다.
대화 원본을 어떻게 모아 둘지(수집 · 보관 한도 · 백업 · 다른 맥과 복제)는 설정 › 「대화 보관」에서 정합니다. 대화 기록 창은 검색과 열람만 합니다.
Claude의 bypass ON/OFF와 Codex의 YOLO ON/OFF를 유지하며, OFF도 명시적으로 적용하므로
그 뒤 바뀐 전역 설정에 따라 ON으로 바뀌지 않습니다. Codex는 승인 정책·샌드박스·승인 처리 주체도 함께 복원합니다.
복원된 모드는 시작 후 알림으로 표시합니다.

기록이 없거나 손상·충돌·지원하지 않는 설정이면 시작하지 않고 이유를 알립니다.
이전에 저장된 프로필 구분 없는 Claude 기록만 있는 경우에도 CLI에서 직접 재개해 새 훅 기록을 남겨야 합니다.
프로세스 확인용 PID가 없는 옛 훅은 상태 보고는 계속되지만 복원 근거로 쓰지 않습니다.
Codex 권한 복원은 0.164.0 이상을 지원합니다. 현재 지원하지 않는 Codex 설정에는 사용자 정의 권한 프로필과 읽기 전용 모드의 네트워크 허용이 포함됩니다.
CLI가 기록하지 않은 변경은 복원할 수 없습니다. FarShell 실행 권한은 자동 승계하지 않습니다.
