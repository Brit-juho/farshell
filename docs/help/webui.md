# 웹 UI 사용 설명서

브라우저에서 Voice Terminal을 쓰는 방법 전체. (CLI는 `vt help concepts`, 음성은 `vt help voice` 참고)

---

## 1. 접속

| 환경 | 방법 |
|------|------|
| 데스크톱 | `http://localhost:7777` |
| 같은 와이파이 모바일 | `http://<맥북IP>:7777` (IP: `ipconfig getifaddr en0`) |
| 어디서든(원격) | `vt mobile` → 나오는 cloudflare HTTPS URL / QR |
| 회사망 등 | `vt mobile --network tailscale` (tailnet 제한) |

> 토큰(`VT_TOKEN`)이 설정돼 있으면 URL에 `?token=...`이 붙습니다. 첫 접속 시 토큰이
> HttpOnly 쿠키로 교환되고 URL에서 제거됩니다(로그/공유 노출 차단).

---

## 2. 탭 = 세션 (가장 중요한 개념)

상단 탭 하나 = 터미널 세션 하나입니다. 두 종류가 있습니다.

| 종류 | 만드는 법 | 탭 `×`로 닫으면 |
|------|-----------|-----------------|
| **tmux 세션** (권장) | `⋯ → tmux 세션`, 또는 자동 attach | **detach(잠듦)** — 세션·claude는 계속 살아있음 |
| **일반 터미널** | 온보딩 `일반 터미널`, `+` | **완전 종료** — 셸과 내용물이 죽음 (복구 불가) |

- **닫아도 안전한 건 tmux 탭입니다.** claude 돌리는 세션은 tmux라 닫으면 그냥 잠듭니다.
- 탭 이름으로 구분: tmux 탭은 세션 이름(`dev` 등), 일반 탭은 짧은 랜덤 id.
- 탭 더블클릭 → 이름 변경. 탭 드래그 → 순서 정렬.

### 세션 관리 패널 (`⋯ → tmux 세션`)

실행 중인 모든 tmux 세션이 상태와 함께 나옵니다.

```
🟢 dev      (1win · 웹에 열림 · claude)          🗑
💤 build    (2win · 잠듦)                         🗑
🖥️ notes    (1win · 데스크톱 attach · vim)        🗑
────────────────────────────────
+ 새 tmux 세션
```

- **이름 클릭** = 깨우기(attach). 이미 웹에 열려 있으면 그 탭으로 전환.
- **🗑 버튼** = 완전 종료(kill). 실수 방지로 **2단계**: 첫 클릭 → `종료?`(빨강), 3초 안에 다시 클릭해야 실제 종료.
- 뱃지: 🟢 웹에 열림 · 🖥️ 데스크톱(iTerm 등) attach · 💤 잠듦(detached)

> 완전 종료는 tmux 세션과 그 안의 claude/셸까지 되돌릴 수 없이 끝냅니다.

---

## 3. 새 세션 시작 위치

새로 만드는 세션(일반 셸 / 새 tmux)은 기본으로 **홈 디렉토리(`~`)** 에서 시작합니다.
다른 폴더에서 시작하려면 `~/.vt.env`에:

```bash
VT_START_DIR=~/projects
```

> 이미 존재하는 tmux 세션을 attach하는 건 그 세션 원래 위치를 유지합니다. 이 설정은
> **새로 만드는** 세션에만 적용됩니다.

## 4. 복사 · 붙여넣기 · 이미지

| 하고 싶은 것 | 방법 |
|--------------|------|
| **복사** | 텍스트 드래그 선택 → 자동 복사 ("복사됨" 표시) |
| 복사 (단축키) | 선택 후 `Cmd+C` (mac) / `Ctrl+Shift+C` (Linux/Win) |
| 복사 (우클릭) | 선택이 있는 상태에서 우클릭 |
| **붙여넣기** | `Cmd+V` / `Ctrl+V`, 또는 우클릭(선택 없을 때), 모바일은 롱프레스 |
| **이미지 붙여넣기** | 스크린샷 등 복사 후 `Cmd+V` → 자동 업로드 → **파일 경로가 터미널에 삽입됨** |

### ⚠️ 드래그 복사가 안 될 때 — tmux 마우스 모드

tmux는 기본으로 마우스 모드(`set -g mouse on`)라, **그냥 드래그하면 tmux가 마우스를
가로챕니다.** 그래서 브라우저 텍스트 선택(→ 자동 복사)이 되려면:

- **`Shift`(또는 mac에서 `Option`) 누른 채 드래그**하세요. → 선택되고 자동 복사됨.
- 우클릭 붙여넣기 / 이미지 붙여넣기는 마우스 모드와 무관하게 바로 됩니다.

Shift 없이 그냥 드래그로 복사하고 싶으면 `config/vt-tmux.conf`에서
`set -g mouse off`로 끄면 됩니다. 단, tmux 스크롤휠·pane 클릭이 사라지고 iTerm 세션에도
같이 적용됩니다.

### 이미지 워크플로 (Claude Code)

이미지를 붙여넣으면 서버 `/tmp/vt-uploads/`에 저장되고 그 경로가 터미널에 입력됩니다.
그 경로를 그대로 claude에 넘기면 됩니다. (📎 파일 업로드 버튼으로도 동일하게 가능)

> 터미널은 텍스트(바이트)만 받는 PTY라 이미지 자체를 "붙여넣어" 화면에 띄울 수는 없습니다.
> 대신 업로드 후 경로를 넘기는 방식입니다.

## 5. 그 밖의 기능

| 기능 | 방법 |
|------|------|
| **검색** | `Ctrl+F` / `Cmd+F` → 터미널 내용 검색 (▲▼로 이동) |
| **파일 업로드** | `⋯ → 파일 업로드` → `/tmp/vt-uploads/`에 저장 |
| **Grid 뷰** | 상단 격자 아이콘 → 모든 tmux 세션 라이브 프리뷰 (변화 시에만 push) |
| **테마** | `⋯ → 테마` → macOS / Catppuccin / Windows 스킨 전환 (기억됨) |
| **맥에서도 열기** | `⋯` 토글 ON → 새 세션 생성 시 iTerm 창도 자동 오픈 (macOS) |
| **핸드오프** | `vt handoff mobile` (폰으로) / `desktop` (맥으로) |

## 6. 음성 바 (하단 우측)

음성 모드로 설치했을 때만 보입니다.

- **🎤 음성 입력**: 탭 → 녹음 → 다시 탭 → STT → 활성 세션에 텍스트 입력
- **🎧 음성 전용 모드** (`⋯`): 터미널 숨기고 큰 마이크만 — 이어폰 조작용
- **이어폰 미디어키** (`⋯`): 이어폰 Play/Pause를 녹음 토글로 사용
- 데스크톱 핫키는 `Ctrl+Shift+V` (voice daemon 실행 시). 자세히는 `vt help voice`

---

## 7. 연결 · 오프라인 동작

- 서버 연결이 끊기면 "서버 연결 끊김" 오버레이가 뜨고 **자동 재연결**을 무한 시도합니다
  (지수 백오프, 최대 30초 간격). 네트워크가 돌아오면 자동 복구.
- 재연결 시 이전 출력(scrollback)이 복원됩니다.
- PWA로 설치 가능(홈 화면에 추가). 정적 자원은 캐시되어 빠르게 로드됩니다.

---

## 8. 자주 겪는 문제

| 증상 | 원인 / 해결 |
|------|-------------|
| 드래그 복사가 안 됨 | tmux 마우스 모드 — **Shift+드래그** (위 4번 참고) |
| 붙여넣기가 안 됨 | 터미널을 한 번 탭해 포커스 후 `Cmd/Ctrl+V`. 클립보드 읽기는 HTTPS/localhost에서만 |
| TUI(claude) 줄이 어긋남 | 탭 전환/새로고침하면 크기 재동기화됨. 계속되면 `vt help troubleshoot` |
| 새 세션이 프로젝트 폴더에서 열림 | `VT_START_DIR` 설정 (위 3번) — 기본은 홈 |
| 탭 닫았는데 claude가 사라짐 | 그건 "일반 터미널" 탭. claude는 tmux 탭(`dev`)에서 쓰세요 |

더 많은 트러블슈팅: `vt help troubleshoot`
