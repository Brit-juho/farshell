# GEMINI.md

Gemini CLI reads this file by default. This repository keeps its agent instructions in
**[`AGENTS.md`](./AGENTS.md)** (the [agents.md](https://agents.md) convention) so that every
CLI gets the same rules.

**Read [`AGENTS.md`](./AGENTS.md) first, then [`CLAUDE.md`](./CLAUDE.md).**

Duplicating the content here would create a second copy to keep in sync, and this repo has
already been bitten by that once (`CLAUDE.md` vs `API.md`, 2026-08-20 — `scripts/check_docs.py`
exists because of it).
